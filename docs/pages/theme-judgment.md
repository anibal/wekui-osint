title:: Theme judgment
type:: concept

- A **theme judgment** is an [[actor]]'s answer to *what is this [[post]] about*: it says a Post carries a [[theme]]. It is one kind of [[judgment]] — append-only and superseding, carrying its Actor and, for an agent, a confidence.
- The slot is the pair **(Post, Theme)**: a Post may carry any number of current theme judgments at once — a Post can be about several things — but at most one current answer for each Theme. Re-judging that same Post-and-Theme supersedes the earlier answer.
- The Theme judged must be an **active** [[theme]] of the same [[event]] as the Post: only the settled What axis can be judged against, and nothing is ever judged across Events.
- **No theme (examined-empty)** — an Actor that has read a Post and found no Theme applies records an examined-empty theme answer for that Post: we looked, and it is about nothing in our What axis — which is not the same as never having read it. It is a [[judgment]]'s none-judgment, superseding against the Post's real theme answers.
- **Set replacement** — reading a Post usually answers its whole set of Themes at once. Giving a Post a new set supersedes the Themes it no longer carries and opens the ones it now does, in one step, so a Post's current Themes always read as one coherent answer from one Actor.
- A Post with no theme judgment and no examined-empty answer is simply **unclassified**: nobody has yet said what it is about.
