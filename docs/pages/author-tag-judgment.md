title:: Author tag judgment
type:: concept

- An **author tag judgment** is an [[actor]]'s answer to *what is this [[author]]*: it says an Author carries an [[author-tag]]. It is one kind of [[judgment]] — append-only and superseding, carrying its Actor and, for an agent, a confidence.
- It is the author-scoped twin of a [[theme-judgment]]: the same mechanism, keyed to an Author instead of a Post.
- The slot is the pair **(Author, Tag)**: an Author may carry any number of current tag judgments at once — the behaviour, institution and stance axes coexist — but at most one current answer for each Tag.
- The Tag judged must be an **active** [[author-tag]] of the same [[event]] as the Author.
- **No tag (examined-empty)** — an Actor that has examined an Author and found no Tag applies records an examined-empty tag answer for that Author, distinct from never having examined it. It is a [[judgment]]'s none-judgment, superseding against the Author's real tag answers.
- **Set replacement** — examining an Author answers its whole set of Tags at once: a new set supersedes the Tags it no longer carries and opens the ones it now does, in one step.
- An Author with no tag judgment and no examined-empty answer is simply **untagged**.
