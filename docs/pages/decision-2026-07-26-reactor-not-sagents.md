title:: Decision — the pipeline runs on Reactor; sagents was misread
type:: decision

- The deterministic pipeline (extract → resolve → verify → render, and the rungs after it) is orchestrated with **Reactor** (`reactor` 1.0.2, the Ash project's step runner): steps declare what they need, Reactor derives the order, retry limits are declared per step, step events stamp the Run receipt, and `async?: false` makes a run fully serial and predictable. Reactor is already a required dependency of Ash — this decision adds **zero dependencies**.
- **The correction this entry exists to record:** the earlier runtime decision ("Sage (sagents) + Elixir LangChain" for orchestration) rested on a misread. A source-level read of `deps/sagents` 0.9.0 (2026-07-26) found it is not a saga engine — no step graph, no compensation, no rollback anywhere in its lib. It is "Sage *Agents*": an LLM-agent loop on Elixir LangChain where the model decides which tool to call next, and pause/resume approves tool calls. It cannot run a fixed pipeline without putting a model over a sequence that has no decisions in it — the doctrine violation. Reactor is the thing the earlier decision was actually describing.
- The `Ash.Reactor` DSL extension is **not** used: plain steps calling the existing domain code interfaces are the idiomatic pattern, and the extension's `transaction` step misbehaves on ash_sqlite (silently non-transactional on the happy path, a misleading raise on failure).
- **What stays open:** the talking-agent layer (conversational driving, merge-judge as a tool, the spend gate) has no settled runtime — sagents + LangChain remains a candidate, decided when that rung arrives; whether to remove the unused `sagents` dependency now or then is the operator's call. `langchain` stays regardless (its `ChatOpenAI` takes a full-URL endpoint, verified compatible with DeepInfra's OpenAI-style API — any future agent loop needs a model client).
- Evidence: the source reads and the weighing are recorded in `docs/orchestration-scenarios.md` (runtime section) and this session's fork discussion; correction banners on `docs/kickstart-agent.md` and `docs/agent-architecture.md` mark their sagents framing as historical.
